# RDCODE LAB V1

A beginner-friendly multi-language AI coding website.

## Features
- JavaScript runtime (browser)
- Python support (Pyodide planned)
- RDCodelanguage (custom scripting interpreter)
- AI Agent for language detection and translation

## Core Idea
Turn code into a universal playground:
User Code → AI Router → Runtime Engine → Output

## Supported Languages (V1)
- JavaScript
- HTML
- CSS
- Python (future)
- RDCodelanguage

## Goal
Make coding simple, visual, and game-friendly for beginners.
